# 출처 및 권리 안내

## 게임

탐정 진구지 사부로 — 등불이 꺼지기 전에 / 일본 보급판(PlayStation).
게임 원작과 원본 자산의 권리는 원 권리자에게 있습니다.
배포하는 파일은 원본 일본 보급판을 사용자가 직접 변환하는 패치입니다.

## 글꼴

Galmuri11 및 Galmuri11-Condensed를 사용합니다.

- 프로젝트: https://github.com/quiple/galmuri
- 사용한 글꼴에 제공된 저작권 표시와 SIL Open Font License 1.1:
  [Galmuri_LICENSE.txt](../LICENSES/Galmuri_LICENSE.txt)

위 글꼴 라이선스는 게임 원본 자산의 사용 권한을 부여하는 문서가 아닙니다.

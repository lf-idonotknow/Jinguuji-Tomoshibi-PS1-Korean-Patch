# 0.8 검증 범위

## 패치 적용 결과

- 배포 적용 스크립트로 실제 원본 BIN에서 한글 BIN/CUE를 생성했습니다.
- 배포 ZIP을 새 폴더에 풀고 그 안의 파일로 다시 적용했습니다.
- 두 적용 결과의 전체 BIN SHA256은 모두 `e59ae345bf56a9b660a448c1341c49c4d4fd86334fadd0e71c0a39f476f1f232`입니다.
- CUE가 공개용 BIN 파일명을 참조하는지 확인했습니다.
- 잘못된 원본은 출력 전에 거부하며, 기존 결과 파일을 덮어쓰지 않는지 확인했습니다.
- ZIP 전체 구성 파일의 무결성, 파일 목록과 해시를 검사했습니다.

## 기준 한글 ROM

- 원래 CD 적재기로 804개 스크립트 구간의 정렬·버퍼 한계·실제 적재 바이트를 검사했습니다.
- 관계도 중앙 이름은 원본 75개 상태에서 원래 출력 경로를 두 GPU 버퍼로 검사했습니다.
- 올리버 말투 교정은 해당 212개 출력 조각의 문자 저장·GPU 생성·DMA 연결을 두 버퍼로 검사했습니다.
- 마지막 교정의 변경 섹터를 역복원했을 때 이전 누적 ROM 전체 해시와 일치했습니다.

## 확인되지 않은 사항

패치와 ZIP을 실제 원본에 적용해 생성한 BIN의 전체 SHA256이 기준 한글 ROM과 같음을 확인했습니다.
검사 환경은 **macOS / Python 3.9 / xdelta3 3.1.0**입니다.

게임의 원래 문자 출력·GPU 제출 경로와 CD 적재 계약을 검사했습니다. 모든 분기를 실플레이한 검증은 아닙니다.
모든 에뮬레이터와 원본·이전 한글판 세이브의 호환성은 아직 확인되지 않았습니다.
문제 제보에는 패치 버전, 실행 환경, 장면과 재현 순서, 스크린샷을 함께 적어 주세요.

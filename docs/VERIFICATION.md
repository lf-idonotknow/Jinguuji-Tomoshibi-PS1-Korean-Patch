# 탐정 진구지 사부로: 등불이 꺼지기 전에 — 0.8 검증 정보

## 패치 적용 확인

macOS에서 **Delta Patcher 3.1.6**으로 배포 패치를 실제 적용했습니다.
`Backup original file` 옵션으로 원본이 보존되고, `PATCHED.bin` 결과 파일이 별도로 생성되는 것을 확인했습니다.
적용 결과의 전체 BIN SHA256은 기준 한글판과 일치합니다.

```text
e59ae345bf56a9b660a448c1341c49c4d4fd86334fadd0e71c0a39f476f1f232
```

제공 CUE의 BIN 참조와 결과 파일명을 대조하고, 배포 ZIP의 구성 파일과 해시를 검사했습니다.
Windows용 Delta Patcher의 공식 배포 파일 구성은 확인했으며 Windows에서의 직접 실행은 미검증입니다.

## 게임 동작 확인 범위

게임의 문자 출력 경로, 화면 출력 데이터와 스크립트 적재 조건을 검사했습니다.
모든 진행 분기를 처음부터 끝까지 실플레이한 검증은 아닙니다.
모든 에뮬레이터·기기와 원본 일본판·이전 작업판의 세이브 데이터 호환성은 전체 확인되지 않았습니다.

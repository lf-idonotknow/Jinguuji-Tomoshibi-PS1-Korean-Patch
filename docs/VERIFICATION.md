# 탐정 진구지 사부로: 등불이 꺼지기 전에 — 0.8.1 검증 정보

## 패치 적용 확인

배포 ZIP에서 꺼낸 패치를 원본 일본 보급판 BIN에 실제 적용하고 전체 BIN SHA256을 대조했습니다.
결과는 이번 수정이 반영된 기준 ROM과 같습니다. 제공 CUE의 참조와 ZIP의 모든 구성 파일 해시도 검사했습니다.

```text
d5a6e91a15c54764ae32b12b01c36d772f3520146b7b41826b1a5a266fb868d7
```

원본과 기존 출력 파일의 보존, 잘못된 원본의 거부도 검사했습니다.
macOS Delta Patcher 3.1.6에서 배포 ZIP의 0.8.1 패치를 실제 적용했습니다.
`Backup original file`과 `Checksum validation`을 켠 상태에서 원본이 보존되고,
별도 생성된 한글판 BIN의 전체 SHA256이 위 값과 같음을 확인했습니다.
Windows에서의 직접 실행은 아직 확인하지 않았습니다.

## 게임 동작 확인 범위

Adrenaline 구동 개선판은 사용자 Vita에서 게임 진입이 확인되었습니다.
그 뒤 이름표 문제까지 수정한 최종 0.8.1은 로컬 Mednafen에서 실제 게임 진입과 이름표 출력을 확인했으며,
최종 수정본의 Vita/Adrenaline 재시험 결과는 아직 확인되지 않았습니다.

최종 ROM의 이름표 2,577개를 원래 출력 함수의 두 화면 버퍼에서 대조했습니다.
글꼴 적재 804개 구간과 스크립트 CD 적재 804개 구간을 검사했습니다.
이 검사는 모든 진행 분기를 처음부터 끝까지 실플레이한 검증을 뜻하지 않습니다.

원본 일본판·0.8·이전 작업판의 세이브 데이터와 다른 기기의 호환성은 전체 확인되지 않았습니다.

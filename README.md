# 탐정 진구지 사부로: 등불이 꺼지기 전에

「탐정 진구지 사부로: 등불이 꺼지기 전에」 PlayStation 일본 보급판의 한글 패치입니다. 최신 버전은 0.8.1입니다.

## 다운로드와 패치 적용

[한글 패치 0.8.1 다운로드](https://github.com/lf-idonotknow/Jinguuji-Tomoshibi-PS1-Korean-Patch/releases/download/v0.8.1/Tomoshibi_Fukyuuban_KO_v0.8.1.zip) · [처음 적용하는 분을 위한 안내](docs/APPLY.md)

Delta Patcher에서 원본 BIN 선택 → 패치 선택 → 원본 보존 옵션 체크 → Apply patch 순서로 적용합니다.
완료 후 한글판 BIN과 함께 제공되는 CUE를 같은 폴더에 두고 에뮬레이터에서 CUE를 엽니다.

## 0.8.1 변경 사항

- PS Vita의 Adrenaline에서 한글 패치판을 PBP(EBOOT.PBP) 파일로 변환해 실행할 수 있도록 호환성을 개선했습니다.
- 0.8의 대사·선택지·수첩·메뉴·이미지·영상 한글화와 글자 배치를 모두 포함합니다.

Vita에서 구동 개선판의 게임 진입을 확인했습니다.
최종 0.8.1의 Vita/Adrenaline 재시험은 아직 확인되지 않았습니다.

## 한글화 내용

- 본편 대사와 선택지 한글화.
- 게임 메뉴, 수첩의 메모·인물 정보·관계도 한글화.
- 진행에 필요한 문서, 지도, 안내 그림의 일본어 한글화.
- 주요 영상의 한글 자막과 일부 영상 화면 글자 한글화.
- 한글 글꼴 적용과 대사창·메뉴에 맞춘 글자 및 문장 배치.

## 이전 버전에서 업데이트할 때

0.8을 사용하셨더라도 패치되지 않은 원본 일본 보급판 BIN에 0.8.1 패치를 적용하세요.
기존 한글판 BIN에 덧씌우지 않습니다. 0.8을 먼저 적용할 필요도 없습니다.
기존 0.8 한글판은 따로 보관한 뒤 새로 만든 BIN/CUE 두 파일을 함께 사용하세요.

## 적용 대상과 원본 확인

| 항목 | 적용할 원본 BIN |
|---|---|
| 판본 | PlayStation 일본 보급판 / Fukyuuban / SLPS-03015 |
| 파일명 | `Tantei Jinguuji Saburou - Tomoshibi ga Kienu Ma ni (Japan) (Fukyuuban).bin` |
| 크기 | 738,819,648바이트 |
| SHA256 | `cc44e8c81ae0f379c2adfc07fdd5dec280e8efb85217115567c8c7f9838ae519` |

파일명만 같아서는 같은 원본이라고 판단할 수 없습니다. 해시는 파일의 내용을 식별하는 값입니다.
일반판이나 이미 한글 패치를 적용한 파일에는 사용할 수 없습니다.

## 이용 시 참고 사항

영어 표기와 장식용 배경의 일본어는 원문을 유지합니다. 타이틀·엔딩 영상 일부도 원본입니다.
영상 자막 주변에 원래 일본어가 일부 보일 수 있습니다.

모든 진행 분기와 모든 에뮬레이터에서의 동작은 확인하지 못했습니다.
원본 일본판·0.8·이전 작업판의 세이브 데이터 호환성도 전체 확인되지 않았습니다.
